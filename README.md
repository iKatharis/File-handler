# File-handler
This is a file mover created in python
To run it, first run the python script. A UI should then open up, choose the directory and choose the file that you would like to mvoe. Next to their respective buttons, a label should show up showing which file or directory you chose. From there, just click the move file button at the bottom and the file will move. If you didn't choose both directory and file an error will show up telling you that you need to choose both of them.
This script also creates a .json file in which it saves your directory so you only need to choose the file you want to move once you've chosen it once. This .json file will not terminate unless you the user deletes it on purpose.
